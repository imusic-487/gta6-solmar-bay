Solmar Bay is an original open-world crime game set in a fictional coastal city. Explore on foot and by car, steal and drive cars through traffic and pedestrians, run three Bayline Couriers delivery missions, take on rival crews in melee combat, and stay ahead of police whose wanted level rises as you cause trouble. A HUD with cash, wanted stars and objectives, a minimap that tracks your current target, a title screen with Continue / New Game, browser save, and procedural sound round it out. Built with Three.js as static files — no build step, no network requests at play time.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome. Controls: WASD to move, mouse drag for the camera, Shift to run, Space to jump, E to interact, M to mute.
